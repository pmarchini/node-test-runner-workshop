# Slidev Presentation Template

A clean and minimal Slidev presentation template with custom theme.

## Requirements

- Node.js >= 18

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

This will start the development server and open the slides in your browser.

## Build

```bash
npm run build
```

## Export

```bash
npm run export
```

## Theme

This template includes a custom theme located in the `./theme` directory. You can customize:

- Colors in `theme/index.ts`
- Layouts in `theme/layouts/`
- Components in `theme/components/`
- Styles in `theme/styles/`

## Getting Started

1. Edit `slides.md` to create your presentation
2. Customize the theme in the `./theme` directory
3. Add your logo to `public/images/logo.png`
4. Start presenting!
